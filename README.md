# infinox

Infinox MT5 계좌로 금(XAUUSD)을 거래하는 파이썬 자동매매(데모 관찰용)와 백테스트 모음.

> **주의: 이 전략은 장기적으로 수익이 검증되지 않았습니다.**
> 마틴의 기본 신호(SAR + RSI50 + H1 SAR)는 2022-01 ~ 2026-10 실제 틱 백테스트에서 전체 PF 0.96이었습니다(2022~2024년 손실, 2025~2026년 수익).
> 지금 규칙(쉬기 필터 전부)은 같은 기간 PF 1.19지만, 필터가 2022~2024년 신호를 대부분 걸러서 거래와 수익이 2025~2026년 금 상승장에 몰려 있습니다.
> 마틴을 쓰면 손실이 나는 시기에 더 빨리 깡통이 납니다. `demo_trader.py`는 **데모 계좌에서 관찰하는 용도**로 만들었고,
> 실계좌는 `--live` 옵션을 줄 때만 실행됩니다.

## 준비물

- Windows PC (MetaTrader5 파이썬 패키지는 Windows 전용)
- Infinox MetaTrader 5 터미널 설치 + **데모 계좌**로 로그인
- Python 3.10 이상

## 설치

```powershell
git clone https://github.com/boozer83/infinox.git
cd infinox
python -m pip install -r requirements.txt
```

## MT5 설정

1. MT5를 켜고 **데모 계좌**로 로그인합니다. 서버 이름은 `InfinoxLimited-MT5Demo`처럼 `Demo`가 들어간 서버입니다.
2. 툴바의 **Algo Trading** 버튼을 눌러 초록색으로 켭니다. 꺼져 있으면 주문이 거부됩니다.
3. **도구 → 옵션 → 전문가 조언자(Expert Advisors)**에서 "알고리즘 거래 허용"이 켜져 있는지 확인합니다.
4. Windows 절전 모드를 끕니다. PC가 잠들면 새 진입이 멈춥니다.
5. **도구 → 옵션 → 차트 → 차트 최대 봉 수**가 10,000 이상인지 확인합니다 (기본 100,000이면 그대로).
   `demo_trader.py`의 급변동 쉬기가 5분봉 20일치(5,620개)를 씁니다. `backtests.download_bars`로 오래된 1분봉을 받으려면 "무제한"으로 바꾸고 MT5를 다시 켭니다.

MT5 터미널 경로는 자동으로 찾습니다. MT5가 여러 개 설치돼 있거나 연결이 안 되면 경로를 직접 지정하세요.

```powershell
$env:MT5_TERMINAL_PATH = "C:\Program Files\Infinox MetaTrader 5 Terminal\terminal64.exe"
```

## 텔레그램 알림 설정 (선택)

진입·청산 때마다 거래 내용과 **오늘/이번주/이번달 수익률**을 보내고, **일일·주간·월간 리포트**를 보냅니다.
설정 파일이 없으면 알림 없이 매매만 합니다.

1. 텔레그램에서 봇(`@boozer_infinox_bot`)을 찾아 `/start`를 보냅니다.
2. 저장소 폴더에 `telegram.json`을 만듭니다. **이 파일은 git에 올리지 않습니다** (`.gitignore`에 등록됨).
   ```json
   {"token": "봇 토큰", "chat_id": null}
   ```
3. chat_id를 자동으로 찾아 저장하고, 테스트 메시지를 보냅니다.
   ```powershell
   python telegram_notify.py --setup
   python telegram_notify.py --test
   ```

파일 대신 환경변수 `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`를 써도 됩니다.

| 알림 | 시점 |
|---|---|
| 진입 | 방향, lot, 마틴 단계, 가격, SL/TP, 최대 손실, 잔고, 오늘/이번주/이번달 수익률 |
| 청산 | 익절/손절, 손익 $와 %, 다음 마틴 단계(또는 정지), 잔고, 오늘/이번주/이번달 수익률 |
| 일일 리포트 | 월~금 23:58 (서버시간, 금 시장 마감 직후) |
| 주간 리포트 | 금요일 일일 리포트 다음 |
| 월간 리포트 | 그 달 마지막 거래일 일일 리포트 다음 |
| 기타 | 시작/종료, 오류로 멈춤, 5번째 진입 손절 정지, 주문 실패, 증거금 부족, 금요일 청산 실패 |

수익률은 이 전략이 실현한 손익 ÷ 기간 시작 시점 잔고입니다. 열린 포지션의 평가손익은 포함하지 않습니다.
리포트는 스크립트가 켜져 있을 때 보냅니다. 꺼져 있던 동안 놓친 리포트는 다시 켰을 때 가장 최근 것 하나만 보냅니다.

## 실행

```powershell
# 1. 연결 확인 (주문 안 함): 계좌 종류가 "데모"로 나오는지 확인
python check_connection.py

# 2. 신호만 확인 (주문 안 함)
python demo_trader.py --dry-run

# 3. 자동매매 시작 (Ctrl+C로 종료)
python demo_trader.py
```

Ctrl+C로 종료해도 열린 포지션은 서버에 걸어 둔 SL/TP로 계속 관리됩니다. 다시 실행하면 그 포지션과 오늘의 마틴 단계를 이어받습니다.

## 매매 규칙 (`demo_trader.py`)

| 항목 | 내용 |
|---|---|
| 종목 / 봉 | XAUUSD 5분봉 |
| 매수 | 5분봉 SAR(0.02, 0.2)이 상승 전환 + RSI(14) > 50 + 마지막 완성 1시간봉 SAR 상승 |
| 매도 | 5분봉 SAR이 하락 전환 + RSI(14) < 50 + 마지막 완성 1시간봉 SAR 하락 |
| 진입 시점 | 신호 봉이 완성되는 즉시 시장가 |
| 포지션 | 한 번에 1개 (보유 중이면 새 신호 무시) |
| 손절 / 익절 | 7.5달러 / 3달러, 주문할 때 서버에 설정 |
| 마틴 | 시작 lot = 그날 시작 잔고 1,000달러당 0.03 lot 손절마다 2배, 익절하면 시작 lot으로, 시작 lot의 5배까지 (1,000달러면 0.03 → 0.06 → 0.12 → 0.15 → 0.15) |
| 마틴 정지 | 연속 손절 시 최대 5번째 진입까지 (익절하면 1번째로 돌아감), 5번째(0.15 lot)에서도 손절이면 그날은 신규 진입 정지 |
| 마틴 초기화 | 서버 날짜가 바뀌면 1번째(0.03 lot)부터 |
| 주말 보호 | 금요일 22:30(서버시간) 이후 신규 진입 안 함, 23:30에 보유 포지션 청산 |
| 미국장 제외 | 매일 15:00~21:00(서버시간, 한국시간 여름 21~03시 / 겨울 22~04시) 신규 진입 안 함 |
| 횡보 정지 | 오늘 완성된 1시간봉 SAR 전환이 3번 이상이면 그날 신규 진입 안 함 |
| 조용한 시장 쉬기 | 신호 봉의 5분봉 ATR(14)이 2.5달러 미만이면 진입 안 함 (`MIN_ATR`) |
| 급변동 쉬기 | 신호 봉의 5분봉 ATR(14)이 최근 20일 5분봉 ATR 중앙값의 2배를 넘으면 진입 안 함 (`MAX_ATR_MULT`). 손절 7.5달러가 변동성에 비해 너무 좁아지는 날을 피함 |
| 성적 기반 쉬기 | 최근 200건(실제 + 가상) 승률이 71.4% 미만이면 가상 진입만 기록하고, 회복하면 실제 진입 재개 (`<로그 폴더>/winrate.json`) |
| 안전장치 | 기본 데모 전용 (`--live`일 때만 실계좌), 매직 넘버 20261017 포지션만 관리, 증거금 부족 시 진입 안 함, 최대 lot 1.0, 하루 손실 한도는 꺼 둠 (마틴 5번째 진입까지), 최고 잔고 대비 평가금 -50% 시 중단 (`demo_log/risk_state.json`을 지워야 재개) |

설정값은 `demo_trader.py` 위쪽 상수(`LOT_PER_1000`, `MARTIN_MAX_LEVEL`, `MAX_LOT_MULT`, `MIN_ATR`, `MAX_ATR_MULT`, `WINRATE_N`, `SL_USD`, `TP_USD`, `FRIDAY_CLOSE` 등)에서 바꿀 수 있습니다.

**최악의 경우**: 5번 연속 손절하면 하루 손실은 7.5 × (0.03+0.06+0.12+0.15+0.15) × 100 ≈ **383달러**(1,000달러 계좌의 38%)입니다. 장 마감 사이 갭이 생기면 손실이 SL보다 더 커질 수 있습니다.

**백테스트 (지금 규칙, 2022-01 ~ 2026-10, 실제 틱 체결, 1,000달러 시작)**: 거래 1,750건, 승률 73.9%, PF 1.19,
최종 11,459달러, 최대 낙폭 30% (청산 잔고 기준), 최악의 날 -23.8%.
마틴은 거래 몇 개만 달라져도 뒤의 단계가 바뀌어 최종 잔고가 크게 흔들리므로(설정을 조금 바꾸면 5천~1만 1천 달러), 잔고보다 PF를 보세요.
급변동 쉬기(×2.0)는 2025년 데이터로 기준을 고르고 2026년에 확인했습니다: 2026년 PF 1.20 → 1.22.

## 추세추종 자동매매 (`trend_trader.py`)

장기 백테스트(2022-01 ~ 2026-10)에서 **5년 모두 PF 1.19 이상**이었던 전략입니다 (스왑 포함, 스왑을 빼면 1.35 이상).
스왑은 지금 MT5 값(1 lot당 매수 -78.33달러 / 매도 +26.13달러 per 밤, 수요일 3배)을 전 기간에 적용했습니다 (`backtests/martin_trend_combo.py`).
과거 스왑은 금리에 따라 달랐고, 매수 스왑이 커서 거래당 손익을 평균 2.6달러/온스 깎습니다.
마틴 전략보다 최근 2년 수익은 적지만, 2022~2024년에도 손실이 나지 않았습니다.

| 항목 | 내용 |
|---|---|
| 종목 / 봉 | XAUUSD 4시간봉 |
| 진입 | 종가가 직전 25봉 최고가 위면 매수, 최저가 아래면 매도 (봉 완성 즉시 시장가) |
| 청산 | 매수는 종가가 직전 12봉 최저가 아래, 매도는 직전 12봉 최고가 위면 시장가 청산 |
| 손절 | 진입가 ± 3 × ATR(14), 주문할 때 서버에 설정. 익절 없음 |
| 수량 | 손절에 걸리면 잔고의 2%를 잃도록 계산 (`RISK_PCT`) |
| 보유 | 평균 7.8일 (백테스트), 주말에도 보유 (스왑 발생). 23:50에 청산했다가 다음 날 재진입해 스왑을 피하는 방법은 이득이 작고 재진입 비용에 민감해서 쓰지 않음 |
| 안전장치 | 데모 계좌 전용, 매직 넘버 20261018 포지션만 관리 |

```powershell
python trend_trader.py --dry-run   # 신호만 확인
python trend_trader.py             # 시작
```

- 기록은 `trend_log/` 폴더, 텔레그램은 같은 봇으로 메시지 앞에 `[추세]`가 붙습니다.
- **잔고 1만 달러 이상 데모를 권합니다.** 손절폭이 1온스당 50~120달러라, 1,000달러 계좌에서는 최소 수량 0.01 lot으로도 거래당 5~12%를 잃을 수 있습니다.
- `demo_trader.py`와 같은 계좌에서 같이 돌려도 서로의 포지션은 건드리지 않습니다. 다만 수익률 계산과 2% 수량 계산이 같은 잔고를 기준으로 섞입니다.
- 계좌를 따로 쓰려면 MT5 터미널이 하나 더 필요합니다. MT5 파이썬 연결은 터미널에 로그인된 계좌 하나만 쓰기 때문입니다. MT5 설치 폴더를 통째로 복사해 두 번째 터미널을 만들고, 거기에 1만 달러 데모로 로그인한 뒤 실행하기 전에 경로를 지정합니다.
  ```powershell
  $env:MT5_TERMINAL_PATH = "C:\MT5_trend\terminal64.exe"
  python trend_trader.py
  ```

## 두 전략 같이 돌리기 (권장)

마틴과 추세추종은 성격이 반대라(마틴: 승률 74%, 작게 자주 / 추세추종: 승률 44%, 크게 가끔) 월 손익 상관계수가 0.2 정도입니다.
마틴 lot을 키우는 것보다 추세추종을 더하는 쪽이 같은 낙폭에서 수익이 훨씬 컸습니다. 같은 계좌에서 두 스크립트를 각각 실행하면 됩니다.

| 2022-01부터 1,000달러 | 최종 | 최대 낙폭 | 최악의 날 |
|---|---|---|---|
| 마틴만 (지금 규칙, 틱 체결) | 11,459달러 | 30% | -23.8% |
| 추세추종만 (1분봉 체결, 스왑 포함) | 2,871달러 | 30% | -15.3% (평가금 기준) |
| **마틴 + 추세추종** (마틴 틱 체결, 추세 1분봉 체결) | **15,701달러** | **29%** | **-19.7%** |

- 2022~2024년은 마틴이 거의 쉬고(ATR 2.5달러 미만) 추세추종이 연 8~10%를 냈습니다. 2025년부터는 마틴이 수익 대부분을 냅니다.
- 낙폭은 청산된 잔고 기준입니다. 열린 포지션의 평가손익까지 넣으면 약 10%p 더 큽니다
  (추세추종이 큰 평가이익을 돌려주고 청산하는 경우가 많아서). 계좌 손실 한도(최고 잔고 대비 평가금 -50%)에는 걸리지 않았지만,
  급변동 쉬기 전 마틴 0.03 + 추세에서는 42%까지 가서 여유가 크지 않았습니다.
- 더 안전하게 하려면 `LOT_PER_1000`을 0.02로 낮춥니다. 1분봉 백테스트(급변동 쉬기 전)에서 낙폭이 41% → 28%, 최악의 날이 -37% → -21%로 줄었고, 최종 잔고는 마틴만 돌릴 때보다 많았습니다.

다른 종목은 효과가 없었습니다 (2026-10 확인): 은·비트코인에 마틴 단타(`gold_rest_others`), 미국 10년물 국채(USNote10Y)와 S&P 500(SPX500)에 같은 추세추종 → 모두 PF 1 미만.

## 기록

`demo_log/` 폴더에 남습니다.

- `trades.csv`: 거래마다 신호 봉, 마틴 단계, lot, 신호 가격, 체결가, **슬리피지**, 스프레드, SL/TP, 청산가, 손익, 청산 사유(TP/SL/CLOSE)
- `events.log`: 5분마다 SAR, RSI, H1 SAR 상태와 진입·청산·정지 기록
- `state.json`: 리포트를 어디까지 보냈는지 기록 (중복 전송 방지)

백테스트에서는 거래당 추가 비용이 0.2달러를 넘으면 우위가 사라졌습니다. 2~4주 운영한 뒤 `trades.csv`의 `slippage` 평균이 0.1달러 이하인지 먼저 확인하세요.

## 백테스트

저장소 루트에서 `python -m backtests.<이름>`으로 실행합니다. 결과 CSV는 실행한 폴더에 저장됩니다.

데이터는 두 가지입니다.
- **실제 틱** (`data/ticks/`, git에 없음): 대부분의 백테스트가 씁니다. MT5가 켜져 있어야 하고, 처음 실행할 때 MT5에서 받아 저장합니다. 4년 10개월치가 수 GB이고 시간이 걸립니다.
- **1분봉 zip** (`data/bars/<종목>_M1_<연도>.csv.zip`, git에 포함): 금·은·비트코인 2022-01부터. `gold_rest_others`, `martin_trend_combo`가 씁니다. MT5 없이 실행됩니다.
  다른 종목은 `python -m backtests.download_bars <종목> [--from 연도]`로 받습니다.

1분봉 체결은 1분 안에 손절과 익절이 둘 다 닿으면 손절이 먼저라고 가정해서, 익절 3 / 손절 7.5처럼 폭이 좁은 마틴에는 보수적입니다.
같은 마틴 규칙이 1분봉 체결로는 1,000달러 → 3,488달러, 실제 틱 체결로는 7,038달러였습니다 (급변동 쉬기 전). 마틴 결과는 틱 체결을 기준으로 보세요.
