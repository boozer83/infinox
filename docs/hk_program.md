- ✅ **역추세형 RSI**: 진입 순간 5분봉 RSI가 매수는 평균 37.6 (중간 50%가 35~41), 매도는 평균 60.8 (57~65). 즉 RSI가 반대쪽에 있을 때 SAR이 뒤집히는 순간 = 반등 초입을 잡음. 1분봉 RSI는 이미 진입 방향으로 넘어와 있음 (매수 때 50~60)

## 3. 마틴 (헤지 마틴 사이클)

### 3-1. 사이클 구조 (✅ 243$ 체험 계좌 10/22 사이클 하나 전체 + 여러 계좌)
| 서버 시각 | 동작 | 가격 | lot |
|---|---|---|---|

| 01:23~ | 매도가 이기면서 **가격이 1$ 내려갈 때마다 매도 같은 lot 추가** | 4138.21 / 4137.17 / 4136.06 | 0.03 x3 |
| 01:31:11 | 이기는 쪽 매도 3개 **묶음으로 한꺼번에 익절** | 약 4135.9 | +11.19$ |
| 01:31 직후 | **같은 방향(매도)으로 2배 lot** 다시 시작, 또 1$마다 추가 | 4135.79 / 4134.94 / 4134.03 | 0.06 x3 |
| ~ | 지는 매수 0.03은 **손절 없이 보유** (최대 -21$/oz) | | |
| 04:12:04 | 사이클 합계가 목표에 닿아 **전부 동시 청산** | 약 4117.5 | 매도 +308 / 매수 -64 |

정리된 규칙
1. ✅ 매수·매도 같은 lot으로 사이클 시작
2. ✅ 이기는 쪽은 1$ 갈 때마다 같은 lot 추가 (불타기, 패널 "Max Pos N / Entry Gap $1.0"). 물타기 아님
3. ✅ 이긴 묶음을 한꺼번에 익절 -> 같은 방향 2배 lot 묶음 재시작 (패널 "MARTIN LV" 1->2->3)
4. ✅ 지는 쪽은 손절 없이 보유
5. ✅ 사이클 합계(확정 + 평가)가 목표에 닿으면 전부 동시 청산
6. 📢 사이클 손실 한도 (패널 Cycle Loss Limit 30%/50%), 최대 5단계(5마틴)

다른 계좌 예
- 10/20 0.54 계좌: 0.05 쌍 -> 0.10 -> 0.20 -> 0.40, 17:25:53 동시 청산 (-515 / +490)
- 10.31 계좌: 1.04 -> 2.08 -> 4.16 (13:25:05 동시 청산 +817), 1.05 -> 2.10 -> 4.20 (20:19:07 +533)
- 45만$ 계좌: 04:07 사이클 청산 매도 +4,316/+4,706/+4,973, 매수 -2,978 -> +11,017
- 9/2 계좌: 매도 4.56 lot x3 (-22,517$ 등) 보유 장면 -> 지는 쪽 보유 위험이 실제로 발생

### 3-3. 홍콩 신호 구조대 (📢 2부 슬라이드)
1. 5마틴 중 반대로 움직여 계좌 리스크 15%
2. 10분 관찰
3. 10분 안에 추가 5% (합계 20%) -> 손익 동결
4. 동결 = 반대 방향 추가 진입으로 매수·매도 lot을 똑같이 맞춤 (예: BUY 1.00 + SELL 0.50 -> SELL 0.50 추가)
5. 동결 상태로 홍콩 신호 매매로 +3%, +5% 쌓아 손실 상쇄 -> 본전 탈출
- 판단: 손절 대신 완전 헤지로 -20%를 얼려 두는 것. 증거금이 묶이고 스왑 비용 발생, 메우는 수단(홍콩 신호)은 실제 승률 60%대 마이너스라 지면 손실이 커짐. 손실 한도 -50% 대신 -20% 동결이라 위험 축소 장치는 맞음
