### 3-3. 홍콩 신호 구조대 (📢 2부 슬라이드)
1. 5마틴 중 반대로 움직여 계좌 리스크 15%
2. 10분 관찰
3. 10분 안에 추가 5% (합계 20%) -> 손익 동결
4. 동결 = 반대 방향 추가 진입으로 매수·매도 lot을 똑같이 맞춤 (예: BUY 1.00 + SELL 0.50 -> SELL 0.50 추가)
5. 동결 상태로 홍콩 신호 매매로 +3%, +5% 쌓아 손실 상쇄 -> 본전 탈출
- 판단: 손절 대신 완전 헤지로 -20%를 얼려 두는 것. 증거금이 묶이고 스왑 비용 발생, 메우는 수단(홍콩 신호)은 실제 승률 60%대 마이너스라 지면 손실이 커짐. 손실 한도 -50% 대신 -20% 동결이라 위험 축소 장치는 맞음
